# analisis_ventas_utn
Proyecto de Análisis de Ventas

Descripción

Este proyecto fue hecho para la materia Organización Empresarial de la Tecnicatura Universitaria en Programación.

El objetivo es analizar un conjunto de datos de ventas utilizando Python, GitHub, Jira y Google Colab, aplicando herramientas de control de versiones y trabajo colaborativo.

Herramientas a utilizar

- Python
- Git
- GitHub
- Jira Software
- Google Colab

Estructura del proyecto

- /datos → archivos CSV utilizados
- /scripts → scripts de Python
- /resultados → gráficos y resultados generados

material  elegido

Análisis de ventas de una pequeña empresa.
